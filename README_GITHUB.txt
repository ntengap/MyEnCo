MY ENGLISH COMPANION — CORAL + MODE FOCUS
1. Décompressez le ZIP et publiez les 6 fichiers directement à la racine du dépôt GitHub.
2. Settings > Pages > Deploy from a branch > main > / (root).
3. Ouvrez l'URL HTTPS de GitHub Pages.
4. Bouton « Mode Focus » dans l'en-tête : bascule immédiate, préférence mémorisée sur l'appareil.
5. En Focus, la traduction de la scène est masquée initialement, avec un bouton pour l'afficher. Le mode normal conserve les traductions visibles.
6. Les trois durées, la navigation, l'audio et les réponses restent accessibles.
7. Pour installer : bouton « Installer l'application » (Android) ou Safari > Partager > Sur l'écran d'accueil (iPhone).
8. En cas d'ancienne version : recharger la page et rouvrir la PWA ; un ancien cache peut persister jusqu'à la prochaine visite.
Aucun dossier d'icônes : les deux PNG nécessaires à la PWA sont à la racine.
